# DSA C++ Practice Repository

This repository is a personal workspace for Data Structures and Algorithms (DSA) practice in C++.

## Purpose

It contains small C++ programs, problem-solving exercises, and practice files used to learn and improve algorithmic thinking, implementation patterns, and competitive-programming habits.

## Project structure

- `demo.cpp` — sample C++ file used for quick testing
- `input.txt` — input used when running the program
- `output.txt` — captured result of the program output
- `practive/` — folder for DSA practice problems and exercises
- `.vscode/` — VS Code task and shortcut configuration for local C++ workflow

## C++ workflow

This repository is designed to work smoothly with VS Code on Windows using MinGW.


## Repository target

This repository is intended for personal DSA learning and progress tracking using GitHub.
